# iBraine AgencyOS Task Tracker — V1

React + Vite + Tailwind CSS dashboard starter for iBraine's client-driven work management system.

## Run
```bash
npm install
npm run dev
```

## Component structure
- `src/components/layout` — Sidebar, Topbar, Shell
- `src/components/brand` — iBraine brand/logo
- `src/components/dashboard` — reusable dashboard cards, queue, activity, teams, projects
- `src/pages/admin` — Admin Mission Control
- `src/pages/employee` — Employee workspace
- `src/pages/client` — Client portal
- `src/pages/projects` — Project detail
- `src/pages/assets` — Asset management
- `src/pages/notifications` — Notification center

## Design direction
Inspired by the supplied Facit dashboard reference: persistent sidebar, airy SaaS cards, activity timeline, project tracker and team summaries. Reworked for iBraine with blue/orange branding and colorful functional accents.

V1 intentionally keeps the product lean: no AI, invoicing, contract generation or deep CRM.
